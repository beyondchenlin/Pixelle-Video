# 视觉锚点二次融合方案

## 1. 方案结论

采用“内容先行，视觉锚点二次融合”的生成方式。

第一阶段只根据文案生成服务于内容表达的画面提示词；第二阶段再把画面提示词和 IP（知识产权角色）视觉锚点描述交给大模型，由大模型分析场景并选择唯一、自然的融合方式，最终输出一条完整的生图提示词。

第二阶段可以在分析过程中比较多种融入方式，但最终只能选择一种方式写入生图提示词。不能把“站在旁边、墙上贴画、桌面摆件”等多个候选同时交给生图模型，否则会提高生成多个角色或多个锚点形态的概率。

## 2. 目标定义

IP（知识产权角色）视觉锚点的主要作用不是解释文案，而是形成视频系列的视觉记忆。

视觉锚点不必在每个画面中成为文案主体，也不必强行执行连接、整理或解释等动作。每个画面只需要满足以下硬性条件：

1. 必须存在视觉锚点。
2. 全画面只出现一个视觉锚点实例。
3. 视觉锚点的核心外观能够被清楚识别。
4. 视觉锚点与画面的风格、透视、光照和空间关系自然一致。
5. 视觉锚点不能替代、遮挡或改变文案中的必要主体和事实。

视觉锚点可以采用以下任一种表现形态：

- 站在主体旁边的角色。
- 场景中的观察者。
- 墙上的单幅贴画。
- 桌上的单个摆件。
- 场景中的单座雕塑。
- 衣服或物品上的单个图案。
- 屏幕上的单个视觉图标。
- 参与文案事件的角色。

具体使用哪一种形态，由第二阶段的大模型根据画面内容判断。

## 3. 总体生成流程

### 3.1 第一阶段：生成纯文案画面

输入原始文案，只生成服务于内容表达的画面提示词，此时不加入 IP（知识产权角色）视觉锚点。

第一阶段同时提取并保护以下内容：

- 文案事实。
- 人物姓名和数量。
- 事件发生的年代。
- 主体动作。
- 核心物品。
- 场景环境。
- 叙事重点。
- 镜头中心。
- 必须保留的因果关系和空间关系。

第一阶段输出：

1. 原始文案事实摘要。
2. 不可改变的画面要素。
3. 可以轻微调整的画面要素。
4. 纯文案画面提示词。

### 3.2 第二阶段：视觉锚点融合分析

第二阶段接收以下输入：

- 第一阶段生成的纯文案画面提示词。
- 第一阶段提取的不可改变要素。
- 视觉锚点的身份描述。
- 视觉锚点的核心识别特征。
- 视觉锚点的禁止变化项。

大模型必须完成以下分析：

1. 识别当前画面的主体和视觉重点。
2. 识别绝对不能改变的文案内容。
3. 判断画面中适合容纳视觉锚点的空间。
4. 判断视觉锚点采用实体角色、贴画、摆件、雕塑、图案或其他形态中的哪一种最自然。
5. 决定视觉锚点的位置、大小、朝向、景深和露出范围。
6. 决定视觉锚点是否需要与人物、物品或环境发生关系。
7. 判断是否需要轻微调整镜头、背景、空白区域、局部光照或小道具。
8. 从候选方式中选择唯一的最终融合方案。

### 3.3 第三阶段：编译最终生图提示词

第二阶段最终只允许输出一套确定结果：

- 一种视觉锚点形态。
- 一个视觉锚点实例。
- 一个确定位置。
- 一个确定尺寸。
- 一个确定朝向和景深关系。
- 一组与场景一致的光照、透视、材质和接触关系描述。
- 一条完整的最终生图提示词。
- 一条禁止重复、倒影、复制和外观泄漏的负向提示词。

分析过程中的其他候选方案不能进入最终生图提示词。最终提示词中不能出现“或者”“也可以”“另一种方式”“同时出现”等会让生图模型产生多种实现的候选式表述。

## 4. 最小改写原则

视觉锚点融合允许对原画面提示词进行必要的局部调整，但必须遵守“只修改融合所必需内容”的原则。

### 4.1 允许调整的内容

- 背景中的小道具。
- 墙面、桌面或货架的局部内容。
- 画面空白区域。
- 镜头的轻微偏移。
- 局部光照和阴影。
- 为容纳视觉锚点增加一个合理载体。
- 不影响主体表达的局部构图关系。

### 4.2 禁止改变的内容

- 文案核心事实。
- 主要人物及其数量。
- 时代背景。
- 主体动作。
- 关键物品。
- 事件关系。
- 整张图的叙事中心。
- 文案明确指定的风格和情绪。

因此，融合阶段不是完全不改动原提示词，而是只做容纳视觉锚点所必需的最小改动。

## 5. 单实例生成约束

“全画面只出现一个视觉锚点”必须在首次生成前落实，不能依赖成图后的补救。

最终生图提示词必须满足：

1. 只描述一个视觉锚点实体。
2. 只选择一种视觉锚点表现形态。
3. 视觉锚点的所有动作都由同一个实体完成。
4. 其他人物、动物、道具和背景不能采用视觉锚点的核心外观。
5. 禁止视觉锚点的副本、倒影、镜像、雕像复制、背景复制和重复图案。
6. 如果视觉锚点表现为贴画、摆件、雕塑或图案，就不能再生成一个实体角色。
7. 如果视觉锚点表现为实体角色，就不能在墙面、屏幕、道具或背景中再次出现其形象。

成图检查只负责审计结果，不能承担首次生成中缺少视觉锚点、出现多个实例或融合方式错误后的主要修复责任。

## 6. 大小与位置规则

视觉锚点可以采用任何合理大小和任何合理位置，不按照固定角色类型预设面积、左右位置或景深。

位置和大小由第二阶段大模型根据以下条件共同决定：

- 文案主体所在位置。
- 画面已有视觉重心。
- 可用空白区域。
- 视觉锚点采用的表现形态。
- 与场景物体的接触和承载关系。
- 透视关系。
- 遮挡关系。
- 视觉锚点是否仍然清楚可识别。

不能仅因为视觉锚点比规划值更大或更小就判定失败。只有出现以下问题时才判定构图不合理：

- 遮挡必要人物或物品。
- 改变文案叙事中心。
- 视觉锚点小到无法识别。
- 视觉锚点大到吞没主要内容。
- 与场景透视、光照或材质不一致。
- 缺少合理的接触、承载或空间关系。
- 以贴纸式悬浮方式突兀叠加在画面上。

## 7. 乔布斯画面示例

### 7.1 第一阶段纯文案画面提示词

> 年轻的乔布斯和沃兹尼亚克在车库工作台前组装电路板，桌面散落电子元件，暖色灯光，乔布斯是画面主体。

### 7.2 第二阶段融合分析结果

画面主体是乔布斯、沃兹尼亚克和电路板，车库后方的工具架属于可以轻微调整的背景区域。视觉锚点采用单个摆件比实体角色进入工作区更自然，不改变人物关系和创业场景。

### 7.3 最终融合描述

> 车库后方的工具架上放置一个斑点犬造型的小摆件，佩戴黑色墨镜和红色项圈，全画面只有这一个斑点犬形象。摆件接受同一暖色灯光，在工具架上产生自然接触阴影，不遮挡乔布斯、沃兹尼亚克和电路板。

最终画面仍然表达乔布斯早期创业，视觉锚点自然存在于场景中，没有被强迫承担与文案不符的动作。

如果画面是一张道路发展图，大模型可以选择让视觉锚点站在道路旁边观察，而不是强行让它拉住道路、连接节点或承担整个文案逻辑。

## 8. 对现有实现的调整方向

现有实现需要调整为：

- 保留“全画面只有一个视觉锚点”的生成前约束。
- 保留视觉锚点核心外观保护。
- 保留文案人物、事实和必要主体保护。
- 删除“视觉锚点必须承担文案认知动作”的强制要求。
- 删除按照参与类型固定位置和面积的规则。
- 删除超过预设面积就直接判定失败的规则。
- 增加独立的“视觉锚点融合导演”阶段。
- 视觉锚点必须启用，不允许关闭后继续生成图片。
- 缺少视觉锚点配置时，任务必须在提交阶段失败。
- 最终提示词只能包含一种融合结果，不能包含候选方案或替代方案。

## 9. 完成标准

实现完成后，每个画面必须满足：

1. 纯文案画面提示词先独立生成。
2. 视觉锚点融合由第二次大模型独立完成。
3. 文案核心事实没有被融合过程改变。
4. 每张图存在且只存在一个可识别的视觉锚点。
5. 视觉锚点的表现形态、大小和位置由当前画面决定。
6. 最终提示词中不存在多个候选融合方式。
7. 视觉锚点与场景的透视、光照、材质和空间关系自然。
8. 首次生成提示词已经具备单实例约束，不依赖成图后的修复。

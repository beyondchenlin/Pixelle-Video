# 分层模板预览工作台剩余功能交接实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成标题、字幕、图片、背景、模板库、即时预览和最终生成链路的统一分层模板能力。

**Architecture:** `LayeredTemplateSpec` 是模板排版唯一事实源；Streamlit 只负责编辑状态和提交 normalized spec；即时预览、模板保存、真实预览帧、HTML screenshot、HyperFrames compiled、ffmpeg manifest 都从同一份 spec 派生。禁止把分层排版继续塞进 `template_params` 或散落在 session/UI/adapter 中。

**Tech Stack:** Python 3.11, dataclasses, Pydantic/FastAPI, pytest, Streamlit, Playwright HTML capture, HyperFrames, ffmpeg.

## 2. 不可妥协原则

- `LayeredTemplateSpec` 是唯一排版事实源；`session_state`、`template_params`、HTML 字符串都不能成为事实源。
- `template_params` 只保留 legacy HTML 模板参数，禁止新增任何分层排版字段。
- API 边界必须用严格 schema 校验完整 spec，不能长期接受裸 `dict`。
- 系统模板、我的模板、最近模板必须走同一套 registry/summary 数据结构。
- 用户上传图片、文件、背景在保存模板前必须物化为 repository asset key，不能保存 `UploadedFile`、临时路径或 preview-only URL。
- 保存模板必须先生成缩略图；缩略图失败则整个保存失败，不能产生半成品 preset。
- 旧 `anchor` 只能在输入 normalize 阶段兼容，新的 UI 和新 payload 只能输出 offset。
- adapter 禁止读取 Streamlit session，只能消费 normalized spec 和显式入参。
- 预览、模板缩略图、HTML screenshot 和最终生成必须使用同一份 spec snapshot，避免“预览正确、导出错误”。
- 不能用最小补丁绕过架构问题；每一步都要补测试，避免留下技术债。

## 3. 与 Stage1/Stage2 的边界

本功能不应修改 Stage1/Stage2 的主线设计目标，也不应重排分镜规划、投影选择、stale dependency、stage-gated delivery loop 的职责。

允许接入的边界：

- 在生成请求参数中携带 `layered_template_spec` 和 `selected_template_preset_id`。
- 在标准 pipeline 的配置、manifest 和 render context 中保存 spec snapshot。
- 在 UI 中消费现有标题、字幕、输出尺寸、媒体尺寸和主媒体位置状态来构建 spec。

禁止越界的行为：

- 不要把分层模板字段混入 Stage1/Stage2 的 planning snapshot 语义。
- 不要让分层模板保存逻辑依赖分镜工作台内部状态。
- 不要修改 Stage1/Stage2 文档或流程来适配本功能，除非发现真实 contract 冲突，并单独提交修复说明。

## 9. 最终验收标准

- 右栏顺序为 `生成视频 -> 即时预览工作台 -> 最近视频`。
- 即时预览显示最终画布比例、输出尺寸、媒体尺寸、主媒体 scale/offset、标题、字幕、图片、背景和多图层效果。
- 图片位置产品 UI 默认中心，只通过 `scale_percent`、`offset_x`、`offset_y` 调整。
- 用户可以添加多个文字层、多个图片/文件层、多个背景层。
- 每个 layer 都能调整位置、尺寸、层级、透明度、旋转和锁定状态。
- 当前配置可以保存为“我的模板”，并出现在模板库中。
- 最近使用 5 个模板显示在即时预览工作台顶部，点击后快速切换并持久化 `last_used_at`。
- 预览、真实预览帧、保存模板缩略图和生成请求使用同一份 normalized `LayeredTemplateSpec`。
- HTML screenshot、HyperFrames compiled、ffmpeg manifest 不各自维护独立排版事实源。
- 所有新增 API、repository、adapter 和 pipeline 行为有自动化测试覆盖。

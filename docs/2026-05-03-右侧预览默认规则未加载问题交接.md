# 右侧预览默认规则未加载问题交接

日期：2026-05-03
分支：`dev`
最新已知同步提交：`1276d8e fix: 恢复无分层模板时的预览工作台`

## 当前现象

右侧“排版/预览工作台”已经恢复显示，但在未生成视频、未刷新服务端预览帧之前，工作台显示：

- `当前规格`
- `暂无可预览的排版规格。`
- `最近模板快捷`
- `暂无预览 HTML，完成一次服务端预览后会显示在这里。`

用户期望：选择默认系统模板后，右侧应立即展示默认模板规则，不应该必须先生成视频或刷新服务端预览才有内容。

## 直接原因

当前右侧工作台把“可展示的当前规则”主要绑定到 `layered_template_spec`：

- `web/components/output_preview.py`
  - `_render_layout_preview_workbench_section()` 只把 `video_params["layered_template_spec"]` 作为 `spec_payload` 传给工作台。
  - `_build_layout_preview_html()` 也依赖 `layered_template_spec` 才能生成即时 HTML 预览。
- `web/components/layout_preview_workbench.py`
  - `render_layout_preview_workbench()` 中 `spec_payload` 转换失败或为空时，进入 `_build_summary_html(spec=None, ...)`。
  - `_build_summary_html()` 在 `spec is None` 时只显示 `暂无可预览的排版规格。`

此前为了修复空分层模板污染生成链路，已经正确过滤了空 `layered_template_spec`。因此默认系统模板如果没有真实分层图层规格，右侧工作台就没有可展示的数据源。

## 不能回退的约束

不要把空的 `layered_template_spec` 重新塞回 `video_params`、生成请求、API、manifest 或渲染链路。

原因：

- 空 `LayeredTemplateSpec.layers == []` 曾导致生成链路误判为分层模板渲染路径，出现新生成视频缺标题、字幕、图片等问题。
- 现在的设计边界应保持为：`LayeredTemplateSpec` 只有在包含真实有效图层时才是权威排版规格。
- 默认系统模板规则展示应是单独的 UI 摘要契约，不能伪装成空分层模板。

## 建议修复方向

从源头补一条“默认模板规则摘要”的 UI 数据契约：

1. 在 `web/components/output_preview.py` 增加类似 `_build_layout_preview_default_summary(video_params)` 的函数。
2. 该函数从当前生成参数中提取可展示规则：
   - `canvas_width`
   - `canvas_height`
   - `media_width`
   - `media_height`
   - `media_placement`
   - `render_backend` 或 `layout_preview_render_summary`
   - `selected_template_preset_id`、`layout_preview_template_summary` 或 `frame_template`
3. `_render_layout_preview_workbench_section()` 调用 `render_layout_preview_workbench()` 时新增参数，例如：
   - `default_layout_summary=_build_layout_preview_default_summary(video_params)`
4. 在 `web/components/layout_preview_workbench.py` 给 `render_layout_preview_workbench()` 增加可选参数：
   - `default_layout_summary: Mapping[str, Any] | None = None`
5. 当 `spec_payload is None` 且 `default_layout_summary` 存在时：
   - 不显示 `暂无可预览的排版规格。`
   - 显示“当前模板规则”
   - 显示画布尺寸、媒体尺寸、主媒体位置、渲染摘要、模板摘要
   - 不显示“刷新真实预览帧”和“保存为我的模板”这类依赖真实分层规格的操作按钮
6. 仍然允许预览 HTML/真实预览帧为空时显示空状态，但不能阻塞规则摘要展示。

## 交接结论

这是一个 UI 数据契约缺口，不是生成链路应该恢复空分层规格的问题。

最佳修复应保持两条路径清晰：

- 生成链路：只接受真实非空 `layered_template_spec`。
- 右侧工作台：在没有真实分层规格时，使用默认模板规则摘要展示当前规则。

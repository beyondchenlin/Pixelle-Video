# Visual Story Engine v2

目标：从源头解决“文章理解、画面路线、IP 融合、频道记忆”混在图片提示词末端导致的技术债。

## 新链路

1. 文章视觉分析：大模型先理解文章，而不是直接生图。
2. 多路线候选：系统生成 3-6 个视觉路线，如认知图解、哲学隐喻、数学模型、化学类比、荒诞漫画、电影化场景、品牌 KV 等。
3. IP 兼容性：每条路线都评估当前 IP/频道视觉签名是否能自然进入。
4. 默认选择：系统按文章适配、记忆点、IP 兼容、频道一致、生成稳定、风险评分选择默认路线。
5. 用户覆盖：Web 可展示候选卡片；用户不选，默认执行；API 直接执行默认路线。
6. 逐帧策略：每帧都有 frame_visual_plan 和 frame_ip_fusion_plan。
7. 质量门：防止 IP 替代文章主体、防止路线丢失、防止帧覆盖不一致。

## 关键设计

- “认知锚点”不是总框架，只是视觉路线之一。
- “IP 设计”是资产层；“IP 融合”是让资产服务当前文章视觉路线。
- 每帧都要有频道记忆点，但不等于每帧都让 IP 正面大出镜。
- 小黑风格只能作为表面风格参考，不能把固定角色语义塞进风格规则。

What this repo does

It turns HTML, timing, and motion into rendered video.

HyperFrames is not just a starter template. It is a structured system for composing scenes, previewing them live, validating quality, and exporting deterministic MP4 output.

HTML + GSAP

Architecture view

The repo is organized around authoring, runtime, and delivery.

Think of the center as the composition contract, with packages and skills feeding into it from different responsibilities.

Core contract
Compositions
HTML structure, `data-*` timing, and a GSAP timeline registered for playback.
packages/cli
Initialize and lint
Scaffold projects, validate structure, and keep authoring reliable.
packages/player
Preview and inspect
A local player runs the composition so edits feel immediate.
packages/registry
Blocks and patterns
Reusable pieces help the system feel more like a toolkit than a blank canvas.
skills/
Agent guidance
The skills teach composition rules, motion, linting, and production workflow.
